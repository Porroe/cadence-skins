Cadence Blue Light 1.0

For the Innioasis Y2 running Y2Linux and Y2Reborn.
Copy this entire CadenceBlueLight folder into Skins on Internal Storage or the SD card, then select Settings > Skin > Cadence Blue Light.

Based on the Big Type skin bundled with Y2Reborn, with visual inspiration from Porroe/adwaitapod-focus.
Original font files and license notices are retained.
